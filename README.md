# 🎉 まちがいさがしアプリ (Spot the Difference)

HTML, CSS, JavaScript で作成した、ポップで本格的な「まちがいさがし」ゲームです！
画像の中に隠れた「小さなアイテム（絵文字）」を制限時間内に探し出しましょう。

## 🎮 遊び方
1. **難易度を選ぶ**: 「かんたん」「ふつう」「むずかしい」の3つからレベルを選んでスタート！
2. **比較する**: 左右（または上下）に並んだ2枚の画像を見比べます。
3. **探す**: 右側（または下側）の画像には、左側にはない「小さな絵文字」が隠れています。
4. **クリック**: 違う場所を見つけたらクリック！「ポンッ」と赤丸が表示されます。
5. **クリア**: 制限時間内にすべての間違いを見つけよう！

## 📊 難易度別の設定
| レベル | 制限時間 | 間違いの数 | 判定の甘さ |
| :--- | :--- | :--- | :--- |
| **かんたん** | 100秒 | 3つ | とても甘い |
| **ふつう** | 60秒 | 5つ | 標準 |
| **むずかしい** | 20秒 | 12つ | とても厳しい |

## ✨ 特徴
- **難易度選択**: プレイヤーのレベルに合わせて3段階の難易度から選べます。
- **ランダム生成**: 10種類の候補から間違いがランダムに選ばれるので、遊ぶたびに場所が変わります。
- **リアルタイム合成**: プログラムで「間違い」を画像の上に合成しているので、特別な画像編集なしですぐに遊べます。
- **ポップなデザイン**: 明るいカラーと楽しいアニメーション。マウスカーソルも虫眼鏡（🔍）に変わります。

## 🛠️ カスタマイズ方法

### 1. 難易度設定を調整する
`script.js` の `difficultySettings` オブジェクトを書き換えることで、時間や数、判定の厳さを自由に調整できます。
```javascript
const difficultySettings = {
    easy: { time: 100, count: 3, threshold: 15, label: 'かんたん' },
    // ...
};
```

### 2. 隠すアイテム（絵文字）の候補を増やす
`script.js` の `allPossibleDifferences` 配列に新しい座標と絵文字を追加できます。
```javascript
const allPossibleDifferences = [
    { x: 15, y: 20, emoji: '🍎' },
    // ...
];
```
