GitHub Pages で簡単に自分だけのゲームを公開できます。

## 🎮 遊び方
1. **比較する**: 左右（または上下）に並んだ2枚の画像を見比べます。
2. **探す**: 画像の上にマウスを乗せると虫眼鏡（🔍）に変わります！
3. **クリック**: 違う場所を見つけたらクリック！「ポンッ」と赤丸が表示されます。
4. **注意**: 間違った場所をクリックすると、画面がブルブル震えます。
5. **クリア**: 60秒以内にすべての間違いを見つけて、お祝いメッセージを表示させよう！

## ✨ 特徴
- **ポップなデザイン**: 明るいカラーと楽しいアニメーションで、遊んでいるだけでワクワクするデザイン。
- **レスポンシブ**: PCでもスマホでも、画面サイズに合わせて快適に遊べます。
- **かんたんカスタマイズ**: 自分の画像や間違いの場所を自由に変更可能。

## 🛠️ カスタマイズ方法
...
### 1. 画像を変更する
`index.html` の `<img>` タグの `src` 属性を、ご自身で用意した画像のパスに変更してください。
```html
<img src="assets/your-image-1.jpg" alt="画像1" id="img-1">
<img src="assets/your-image-2.jpg" alt="画像2" id="img-2">
```

### 2. 間違いの場所を設定する
`script.js` の冒頭にある `differences` 配列を編集します。
- `x`: 画像の左端からの位置（0〜100%）
- `y`: 画像の上端からの位置（0〜100%）

```javascript
const differences = [
    { x: 25, y: 40, found: false },
    { x: 60, y: 20, found: false },
    // 必要な数だけ追加
];
```

### 3. 制限時間を変更する
`script.js` の `timeLeft` 変数の値を変更することで、制限時間を調整できます。

## デプロイ方法 (GitHub Pages)
1. GitHub リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** を `main` に設定して **Save** をクリックします。
3. 数分後、サイトが公開されます。
