# 🌑 虚構の裂け目 (The Fissure in Reality)

> 「世界は二つある。一つは真実、もう一つは... 綻びだ。」

HTML, CSS, JavaScript で構築された、深淵を覗き込む「違和感」の観測儀です。
二つの対照的な世界を見比べ、現実に紛れ込んだ「虚像」をすべて暴き出してください。

## 📜 禁忌の断章（背景）
この世界には、時折「真実」の裏側に潜む「虚構」が染み出してくる場所がある。
君の任務は、並べられた二つの光景を観測し、本来そこにあるはずのない「異物」を特定することだ。
観測を誤れば、世界はその拒絶反応として激しく歪むだろう。
すべての違和感を暴いたとき、君は一つの解明に辿り着く。

## 🕯️ 観測の儀
1. **深淵の深さを選ぶ**: 「浅瀬」「中層」「深淵」の三層から、自身の覚悟に合った深度を選択してください。
2. **比較する**: 左側の「真実」と右側の「虚像」を慎重に見比べます。
3. **探す**: 「虚像」には、本来存在し得ない「異物（画像）」が紛れ込んでいます。
4. **観測**: 違和感を覚えた場所を触れてください。正しければその場所は青白く発光し、誤れば世界はグリッチを起こして拒絶します。
5. **調律**: 精神を集中させるため、🔊/🔇ボタンで深淵の音（BGM）を制御できます。
6. **解明**: すべての違和感を暴き出したとき、真実は開示されます。

## 📊 深淵の階層設定
| 深度 | 異物の数 | 観測の容易さ |
| :--- | :--- | :--- |
| **浅瀬** | 3つ | 極めて明瞭 |
| **中層** | 5つ | 標準的 |
| **深淵** | 12つ | 困難を極める |

## 🌙 特徴
- **深淵の視覚効果**: 暗色と幽玄なグローエフェクトによる没入感のあるデザイン。
- **深淵の響き**: 雰囲気あるBGM「After_the_Last_Click.mp3」が観測を彩ります。
- **現実の歪み（グリッチ）**: 誤った観測を行うと、世界が歪むグリッチアニメーションが発生します。
- **異物の実体化**: `image.png` が虚構の証（アイコン）として世界に現れます。
- **静謐な体験**: ポップさを排除し、神秘的で少し不気味な雰囲気の中での探索。

## 🛠️ 儀式のカスタマイズ

### 1. 深度の調整
`script.js` 内の `difficultySettings` を書き換えることで、異物の数や観測の精度を調整できます。

### 2. 異物の実体（アイコン）を変更する
プロジェクトのルートにある `image.png` を差し替えることで、世界に現れる異物の姿を変えることができます。

### 3. 異物の出現座標を調整する
`script.js` の `allPossibleDifferences` に、異物が現れるべき座標を刻んでください。
```javascript
const allPossibleDifferences = [
    { x: 15, y: 20 },
    // ...
];
```
