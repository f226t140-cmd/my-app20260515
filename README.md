# 🎉 まちがいさがしアプリ (Spot the Difference)

HTML, CSS, JavaScript で作成した、ポップで本格的な「まちがいさがし」ゲームです！
画像の中に隠れた「小さなアイテム（絵文字）」を制限時間内に探し出しましょう。

## 🎮 遊び方
1. **比較する**: 左右（または上下）に並んだ2枚の画像を見比べます。
2. **探す**: 右側（または下側）の画像には、左側にはない「小さな絵文字（🍎や⭐️など）」が隠れています。
3. **クリック**: 違う場所を見つけたらクリック！「ポンッ」と赤丸が表示されます。
4. **注意**: 間違った場所をクリックすると、画面がブルブル震えます。
5. **クリア**: 60秒以内に5つの間違いをすべて見つけよう！

## ✨ 特徴
- **リアルタイム生成**: プログラムで「間違い」を画像の上に合成しているので、特別な画像編集なしですぐに遊べます。
- **ポップなデザイン**: 明るいカラーと楽しいアニメーション。マウスカーソルも虫眼鏡（🔍）に変わります。
- **レスポンシブ**: PCでもスマホでも、画面サイズに合わせて快適に遊べます。

## 🛠️ カスタマイズ方法

### 1. 隠すアイテム（絵文字）を変える
`script.js` の `differences` 配列にある `emoji` を書き換えるだけで、好きなアイテムを隠せます。
```javascript
const differences = [
    { x: 20, y: 35, found: false, emoji: '💎' },
    { x: 55, y: 20, found: false, emoji: '👻' },
    // ...
];
```

### 2. 背景画像を変更する
`index.html` の `<img>` タグの `src` を好きな画像URLに変更してください。
```html
<img src="https://picsum.photos/id/100/600/400" alt="画像1">
```

### 3. 制限時間を変更する
`script.js` の `timeLeft` 変数の値を変更することで、制限時間を調整できます。

## デプロイ方法 (GitHub Pages)
1. GitHub リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** を `main` に設定して **Save** をクリックします。
3. 数分後、サイトが公開されます。
