# 🌑 虚構の裂け目 (The Fissure in Reality)

HTML, CSS, JavaScript で構築された、深淵を覗き込む「違和感」の観測儀です。
二つの対照的な世界を見比べ、現実に紛れ込んだ「虚像」をすべて暴き出してください。

## 🕯️ 観測の儀
1. **深淵の深さを選ぶ**: 「浅瀬」「中層」「深淵」の三層から、自身の覚悟に合った深度を選択してください。
2. **比較する**: 左側の「真実」と右側の「虚像」を慎重に見比べます。
3. **探す**: 「虚像」には、本来存在し得ない「異物（記号）」が紛れ込んでいます。
4. **観測**: 違和感を覚えた場所を触れてください。正しければその場所は青白く発光し、誤れば世界はグリッチを起こして拒絶します。
5. **解明**: すべての違和感を暴き出したとき、真実は開示されます。

## 📊 深淵の階層設定
| 深度 | 異物の数 | 観測の容易さ |
| :--- | :--- | :--- |
| **浅瀬** | 3つ | 極めて明瞭 |
| **中層** | 5つ | 標準的 |
| **深淵** | 12つ | 困難を極める |

## 🌙 特徴
- **深淵の視覚効果**: グラスモーフィズムと暗色、そして幽玄なグローエフェクトによる没入感のあるデザイン。
- **現実の歪み（グリッチ）**: 誤った観測（クリック）を行うと、世界が歪むグリッチアニメーションが発生します。
- **異物のランダム配置**: 観測のたびに異なる異物が異なる場所に現れます。
- **静謐な体験**: ポップさを排除し、神秘的で少し不気味な雰囲気の中で「間違い」を探し出す独自の体験。

## 🛠️ 儀式のカスタマイズ

### 1. 深度の調整
`script.js` 内の `difficultySettings` を書き換えることで、異物の数や観測の精度を調整できます。
```javascript
const difficultySettings = {
    easy: { count: 3, threshold: 15, label: '浅瀬' },
    // ...
};
```

### 2. 異物の追加
`script.js` の `allPossibleDifferences` に、深淵から召喚したい新たな記号（絵文字）と座標を刻んでください。
```javascript
const allPossibleDifferences = [
    { x: 15, y: 20, emoji: '👁️' },
    // ...
];
```
